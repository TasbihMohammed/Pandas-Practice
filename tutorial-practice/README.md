# Pandas Tutorial Practice

This folder contains the code and datasets used while following a Pandas tutorial.

## Contents

- **Notebook:** Jupyter Notebook containing the code examples and practical exercises from the tutorial.
- **Datasets:** The datasets used to practice data manipulation, filtering, cleaning, and analysis with Pandas.

## Goals

- Practice Pandas fundamentals through hands-on examples.
- Understand common data manipulation and analysis techniques.
- Build a foundation for solving independent Pandas tasks.
